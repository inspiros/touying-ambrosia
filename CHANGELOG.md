# Changelog

## 0.1.0 - 2026-10-16

- Initial institution-neutral release, extracted from Touying GREYC Ambrosia; requires Typst 0.15+ and Touying 0.8.0.
- Separate extensible flavors, composable color palettes, branding, and navigation; include the Portico preset with an optionally painted sidebar.
- Add fitted title/ending layouts, multiple primary logos, collaborator records, linked affiliations, configurable appendix numbering, and bounded footers.
- Support configurable outline leaders and an optional Pergamon recipe for author-highlighted publication lists.
- Provide configurable navigation, optional PDF controls, section progress, and fitted list/cards/path agendas.
- Add styled nested blocks, badges, text/code/quote helpers, credit cards, palette showcases, and roadmaps with custom time units.
- Share author-year markers across footnotes, inline citations, and bibliography entries.
- Support measured image-caption placement and linked slide previews with an optional SVG export helper.
- Include an illustrated manual, private pdfpc/split-page notes workflows, commented examples, preview galleries, local development installers, and IDE-completable metadata configuration.
