# Ambrosia User Guide

Start with the [package README](../README.md), [illustrated manual](manual.pdf) ([source](manual.typ)), or
[complete starter](../template/template.typ). The [API index](api.md) lists public
functions and their scoped equivalents.

## Design Your Presentation

- [Flavors](flavors.md): slide geometry and defaults.
- [Palettes](palettes.md): preset colors, accent seeds, and role overrides.
- [Branding](branding.md): primary and partner logo collections.
- [Title Layouts](title-layouts.md) and [Ending Layouts](ending-layouts.md).
- [People](people.md): authors, linked affiliations, email, short footers, and appendix numbering.

## Guide The Audience

- [Navigation](navigation.md): bands, sidebars, rails, buttons, and progress.
- [Agendas](agendas.md): fitted lists, cards, and paths.
- [Navigation Families](beamer-navigation.md): how the choices compare.
- [Presentation Patterns](presentation-patterns.md): composing ordinary slides.

## Build Your Content

- [Utilities](utilities.md): blocks, text hierarchy, badges, and citations.
- [Image Slides](image-slides.md): captions, credits, and placement.
- [Roadmaps](roadmap.md): fractional time spans, phases, tasks, and milestones.
- [Slide Previews](slide-previews.md): linked thumbnails and optional export.
- [Credits](credits.md): optional theme credit cards.
- [Diagram Recipes](diagram-recipes.md): standalone experimental diagrams.

[Institution wrappers and custom flavors](extensions.md) cover extensions using
the public API. Working on Ambrosia itself starts with [CONTRIBUTING.md](../CONTRIBUTING.md).
